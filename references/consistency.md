# 人物一致性 · 写法手册

> 先说清楚一件事：**没有任何提示词能强制模型锁脸。** 一致性是「写法纪律 + 概率」，不是保证。
> 本文件只讲怎么写，不讲怎么生成。

---

## 一、四个层次的可控度

按实际有效程度从高到低排：

| 层级 | 手段 | 有效度 | 说明 |
|---|---|---|---|
| 1 | 人物段落逐字复制 | 高 | 同等条件下最稳的一条 |
| 2 | 穿戴物与配饰逐项点名 | 高 | 防中途消失，比锁脸更容易做到 |
| 3 | 强锁脸指令 | 中低 | 提高概率，不保证结果 |
| 4 | 参考图 | 低 | 对锁脸帮助有限，别指望 |

---

## 二、具体写法

### 2.1 人物段逐字复制

多段视频里，**人物描述整段复制粘贴**到每条提示词，不允许改写、缩写、同义替换。

改写是变脸的第一诱因——哪怕只是把「浅棕微卷短发」写成「棕色卷发」，模型也会当成两个人。

### 2.2 穿戴物点名法

比锁脸更实用、更容易验证的一条。逐项列出人物身上**不该变的东西**：

```text
她戴玳瑁色抓夹把浅棕盘发夹住，金色小圆环耳环，米白针织开衫内搭白色罗纹背心，胸前挂着酒红色安全带，以上全部全程保持原位。
```

检查方法很简单：成片里抓夹还在不在？耳环形状对不对？安全带位置有没有跳？——这些都是肉眼能查的，比"像不像本人"客观得多。

### 2.3 强锁脸指令（提高概率用）

放在 L2 主体锁开头：

```text
视频中的人物必须是参考图中的同一人。脸型、五官间距、鼻唇比例、脸部轮廓与参考图严格一致，全程不得漂移、不得变成另一张脸、不得网红脸化。以参考图的人脸身份为最高优先级。
```

但要如实告诉用户：**这条能提高概率，不保证结果。**

### 2.4 参考图范围声明

参考图不要让它"全参考"，只声明需要的部分：

```text
参考图仅参考面部特征与发色发型，不参考服装、配饰与背景。
```

声明范围越小，模型乱抄的余地越小。

### 2.5 否定式锚定（写在 L5 闸门）

```text
不要面部漂移、不要脸型变化、不要五官比例变形、不要手指畸形、不要衣着颜色改变。
```

### 2.6 神态纪律（防假人的关键）

实测中，**夸张表情比穿模更常见**，而且一眼就假。写了自然微表情那一层之后，成片真实度立刻上台阶。

指定为：
```text
只做自然松弛的日常微表情——轻微眨眼、说话时嘴角自然放松、偶尔轻点头。
```
禁止：
```text
不要瞪眼惊讶、不要僵硬露齿笑、不要闭眼大笑、不要脸型发胖变圆。
```

## 三、交付时必须告知用户的三句话

1. 内置视频的人物一致性是弱项：跨段可能换脸，参考图可能不像。
2. 我会用逐字复制 + 穿戴物点名 + 强锁脸指令尽量稳，但不承诺 100%。
3. 要真正锁脸，换 Seedance 2.5 或 MiniMax H3 这类支持强参考的通道。

---

## 四、升级路径（超出本 skill 范围，主动告知）

| 需求 | 方案 |
|---|---|
| 严肃锁脸 | 换第三方强参考模型 |
| 长期固定角色 | 先用 `character-refs` 出一套参考图，再写提示词 |
| 极致一致 | LoRA / FaceID 类方案，属重型工程，另行评估 |

## 五、快速检查表

- [ ] 人物段在多条提示词里逐字一致？
- [ ] 发饰、耳饰、衣着、穿戴物逐项点名？
- [ ] 有没有写"全程保持原位"？
- [ ] 神态限定为自然微表情？
- [ ] 夸张表情进了 L5 限制清单？
- [ ] 交付时说了"不保证像"？
