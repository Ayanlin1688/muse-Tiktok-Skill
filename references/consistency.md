# 人物一致性写法

> 诚实线：没有任何提示词技巧能强制平台锁脸。一致性是"写法纪律 + 概率"，不是保证。
> 本文件只讲**怎么写**，不讲怎么生成。

## 写法手段（按实测有效性排序）

1. **人物描述逐字复用**：同一段人物描述原样粘贴进每条分段提示词，改写是变脸第一诱因。
2. **强锁脸指令**（写在提示词开头，提高概率但不是保证）：
   ```
   视频中的人物必须是参考图中的同一人。脸型、五官、眉眼间距、鼻唇比例、
   脸部轮廓与参考图严格一致，全程不得漂移、不得变成另一张脸、不得网红脸化。
   以参考图的人脸身份为最高优先级。
   ```
3. **参考图范围声明**：只参考声明的部分（"只参考面部特征，不参考服装配饰发型背景"），减少模型乱抄。
4. **否定式锚定**：限制清单写 `不要面部漂移、不要身体比例变化、不要衣服变形、不要手指畸形`。
5. **参考图（弱）**：内置视频参考图对锁脸帮助有限（2026-10-05 以晴实验：强锁脸指令仍不像本人）。可用，但别指望。
6. **多段一致性**：每条提示词的人物段整段复制，段首加"与本片其他段落为同一人物"声明。

## 交付时必须说的三句

- 内置视频锁脸是弱项，跨段可能换脸，参考图可能不像。
- 我会用逐字复用 + 强锁脸指令尽量稳，但不承诺 100%。
- 要锁脸走 Seedance 2.5 / MiniMax H3（本机有 `seedance-2-5-video-director` / `minimax-h3-tiktok-ecommerce`）。

## 升级路径（本 skill 不做，主动告知）

- 严肃锁脸需求 → 换第三方视频模型。
- 长期固定角色 → 先用 `character-refs` 出参考图，再写提示词。
- LoRA / FaceID 属重型方案，另行评估。
