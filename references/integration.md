# 与本机工具链的衔接

> 本 skill **只产提示词**。生成用你自己的工具；下面只写「提示词怎么和上下游对接」。

## 一句话分工

| 环节 | 谁做 |
|---|---|
| 写提示词 | 本 skill |
| 生成视频 | 你自己的工具 |
| 拼接 / 剪 / 配音 / 合成 | 你自己的工具 |
| 提示词写法检查 | 本 skill（14 项自检） |

## 生成前：需要素材或镜头设计时

- `seedance-2-5-video-director`：复杂镜头、导演风格、长片结构。它产出的 prompt 可以按 5L 结构**归位**后再用（不直接透传，字段要重排）。
- `minimax-h3-tiktok-ecommerce`：美区带货的真实感写法（七层正向画像 + 铁律），可参考其"把画面做脏"的思路。
- `character-refs`：需要真人参考图时，先出图，再拿图当参考图写提示词。
- `ecommerce-detailpage-replica`：电商图/海报复刻，产出参考图与提示词。
- `hook-opening-master-*`：短剧开幕钩子，给叙事结构，再拆成 10 秒段。

## 下游：拿到提示词之后

- 直接粘进你的工具。参数表里的画幅/时长/参考图顺序按你工具的界面填。
- 如果工具支持接续（如 snapshot / 首帧延续），多段片按拆段表顺序跑，后段用前段产物接续。
- 跑完发现问题，把现象带回来：说清"哪一段、什么现象"，我按失败改法速查表改提示词。

## 可选脚本

`bin/` 里有两个脚本，**你自己的工具已覆盖就不用管**：

- `extract_frames.py`：抽帧自查（想自己看画面有没有吃进提示词时用）。
- `stitch.py`：多段无损拼接（工具不支持拼接时用）。

## 交接规则

- 生成前环节产出的 prompt 按 5L 结构归位后再交用户定稿，不直接透传。
- 返修时只改对应那一段的提示词，不重写整片。
- 观察与推断分离：没验证过的写法标"未验证"，不写成结论。
