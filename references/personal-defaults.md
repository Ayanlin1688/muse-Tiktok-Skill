## 二、一致性默认项（v7.0 双锁契约）

1. **产品不变量五项全写**：材质透光性、几何形状、颜色分区、部件白名单、相对手掌比例（**不用任何数字尺寸**）。
2. **人物不变量全程锁定**：发饰（抓夹/发圈）、耳饰、衣着纹理、穿戴物（安全带/围巾）点名后不得中途消失。
3. **唯一文字白名单**：产品自带标签写清朝向与内容；主图促销大字一律排除。
4. **部件白名单**：只用参考图中真实存在的部件，严禁脑补新配件。

## 三、动作安全默认项（防穿模与变形）

- **Tier1 持续微动**为默认层（呼吸、眨眼、发丝、手臂微晃）。
- **Tier2 单一受控动作**：每段只准 1 个（微倾、轻触、轻按、单指弹）。
- **Tier3 高危动作默认封杀**：10 秒内禁止「拔盖+喷洒+换手+盖回」连续拆装；必须展示开盖状态时，拆成独立一段以「已开盖」开场。
- **只手任务守恒**：最多 2 个手部接触点；单手托住产品中下段，手指不得遮挡正面标签。

## 四、双平台硬隔离默认项

- **TikTok Shop 美区**：纯英文提示词 + 北美本地人设 + 美式英语或美西语口播 + 美式车内/家居场景 + Listing 一致性声明。
- **抖音电商**：纯中文提示词 + 中国本土人设 + 普通话或指定方言 + 中国家庭场景。
- **未指定平台**：跨境英文主图默认双版本同时交付（美区英文版 + 抖音中文版），但两版内容独立生成，绝不互相污染。

## 五、零违规默认项

- **零数字尺寸**：`cm / inch / " / ft / mm / ml / oz / pcs` 全部清零，改用人体或家居比例参照。
- **零价格**：`$ / ￥ / 元 / 折 / off` 一律不写。
- **零夸大**：`best / #1 / perfect / 100% / 最好 / 第一 / 绝对` 一律不写。
- **零功效**：`cures / 修复 / 治疗 / 零甲醛` 一律不写。
- **交付前必须跑**：`bin/validate_ecommerce_prompt.py --market us|cn` 零错误才交付。
