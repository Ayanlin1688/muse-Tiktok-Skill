# 多段拆段指南（可选）

> 本 skill 只产提示词。这里只讲**怎么把 >10 秒的需求拆成多条提示词**，以及两个可选脚本。
> 拼接、验片由你的工具完成；不用脚本可以整节跳过。

## 一、拆段表（交付时一起给）

| 段 | 覆盖秒数 | 镜头数 | 本段任务 | 接续方式 |
|---|---|---|---|---|
| seg1 | 0–10s | 3 | 建立人物 + 场景 + 钩子 | 首段 |
| seg2 | 10–20s | 2 | 发展 / 情绪转折 | 延续 seg1 同一人物场景光线 |
| seg3 | 20–30s | 3 | 收尾 / 情绪落点 | 延续 seg2 |

## 二、拆段三条硬规则

1. **每段独立完整**：人物、场景、光线、限制清单都要重写一遍，不能写"同上"。
2. **人物段落逐字复制**：三段之间一个字都不改，改写是变脸第一诱因。
3. **段首声明接续**：`本段为 30 秒短片的第 2 段（10–20 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。`

## 三、每段提示词结构

```
[本段为 N 秒短片第 K 段（X-Y 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致]
[时长/画幅] [本段一句话场景]
人物：（与第 1 段逐字一致）
场景：（与第 1 段逐字一致）
剧情节拍：
  0-3秒：...
  3-7秒：...
  7-10秒：...
镜头语言：...
声音：...
限制：...
```

> 每段只写本段的 2–3 个镜头，不写全片。

## 四、可选脚本（你的工具已覆盖就忽略）

### 抽帧自查 `bin/extract_frames.py`

想自己看画面有没有吃进提示词时用：

```powershell
python "$env:USERPROFILE\.dsh\skills\muse-video-prompt-skill\bin\extract_frames.py" "seg1.mp4" 3
```

输出 `seg1-f1.png … seg1-f3.png`，均匀抽帧。

### 无损拼接 `bin/stitch.py`

工具不支持拼接时用；会先校验尺寸/编码，不一致直接报错：

```powershell
python "$env:USERPROFILE\.dsh\skills\muse-video-prompt-skill\bin\stitch.py" `
  --out "成片-full.mp4" "seg1.mp4" "seg2.mp4" "seg3.mp4"
```
